Proyecto 1

Título: Plantilla Flask v2

Contexto: Se requería diseñar una arquitectura base ligera y modular en el backend utilizando Flask para el despliegue rápido de herramientas de automatización, scripts de control y tableros de datos (dashboards). El principal desafío era construir una interfaz de usuario avanzada, responsiva y altamente personalizable (UX) sin la necesidad de sobrecargar el proyecto implementando frameworks pesados o complejos de JavaScript en el frontend.

Stack tecnológico: [Python (Flask), JavaScript, CSS3, HTML5]

Solución: Se desarrolló un entorno desacoplado donde Flask gestiona las rutas y la lógica modular de manera limpia. Para la interfaz, se implementó un sistema de inyección dinámica de variables de tema desde JavaScript, manipulando las propiedades raíz (:root) del CSS en tiempo real para permitir el cambio de paletas de colores de forma fluida y persistente.

Ejemplo: El sistema permite al usuario alternar entre múltiples temas visuales con un solo clic, logrando que toda la interfaz mute y mantenga la persistencia cromática de forma inmediata. Al interactuar con los botones de la cuadrícula de acciones ("Inicio", "Explorar", "Configurar", "Contacto"), se dispara un evento en JavaScript que añade la clase activa al botón presionado y traslada dinámicamente el foco del color al contenedor del footer]

Impacto: Se logró una reducción drástica en el tiempo de configuración inicial para nuevos desarrollos web o paneles de automatización. Al eliminar frameworks de frontend comerciales, se obtuvo un cascarón con un rendimiento de carga óptimo, código limpio, mantenible y una arquitectura base reutilizable que permite a otros desarrolladores e ingenieros de datos integrar endpoints de backend en cuestión de minutos
